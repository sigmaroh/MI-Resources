## File Format

Each exercise file contains:

1. **Header** - Exercise sheet number and title
2. **Question** - The exercise problem statement
3. **Solution** - Step-by-step solution with detailed explanations

## How Files Were Generated

The exercises were extracted from `exercises-01-agents-solutions-merged.pdf` using:
1. `parse_exercises.py` - Extracts and creates individual Markdown files
2. `convert_to_pdf.py` - Converts Markdown files to PDF format using Chromium headless

## Usage

- **For reading**: Open the PDF files for best formatting
- **For editing**: Edit the Markdown files and regenerate PDFs if needed
- **For searching**: Use grep on Markdown files to search across all exercises

## Notes

- Some exercises may contain references to figures or diagrams that were not fully captured in text extraction
- Mathematical notation is preserved as plain text/Unicode where possible
- Optional exercises are marked in their titles
